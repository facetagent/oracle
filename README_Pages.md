Les prompts pour Calude Code:    

Prompt 1:
Tu es un expert Oracle APEX 26.1 et APEXLang. 
Génère un package APEXLang propre, validable par SQLcl, pour un CRUD Customer avec 3 pages :

TABLE CUSTOMER :
    customer_id NUMBER GENERATED BY DEFAULT AS IDENTITY,
    name        VARCHAR2(200) NOT NULL,
    email       VARCHAR2(320),
    phone       VARCHAR2(20)

CONTRAINTES APEXLANG :
- Utilise la syntaxe APEXLang officielle (page, region, source, layout, pageItem, action, linkTarget, edit).
- Utilise des Interactive Reports pour les pages 10 et 11.
- Utilise une région type "form" pour la page 20.
- Utilise le bloc edit { enabled: true, allowedOperations: [add update delete] } pour la région Form.
- Utilise des pageItem avec source.formRegion et source.column.
- Utilise validation.required pour les champs obligatoires.
- Utilise des actions avec behavior.type = redirectPage.

PAGES À GÉNÉRER :

PAGE 10 — Customer List (Email View)
- Interactive Report
- Colonnes : name, email
- Lien Edit → Page 20 (P20_CUSTOMER_ID)
- Lien View → Page 20 (P20_CUSTOMER_ID + P20_MODE='VIEW')
- Bouton : View Phone List → Page 11
- Bouton : New Customer → Page 20

PAGE 11 — Customer List (Phone View)
- Interactive Report
- Colonnes : name, phone
- Lien Edit → Page 20
- Lien View → Page 20
- Bouton : View Email List → Page 10
- Bouton : New Customer → Page 20

PAGE 20 — Customer Form (CRUD)
- Région type form
- Champs : name (required), email, phone
- Boutons : Save, Delete, Cancel
- Cancel → Page 10

Génère uniquement le code APEXLang.
